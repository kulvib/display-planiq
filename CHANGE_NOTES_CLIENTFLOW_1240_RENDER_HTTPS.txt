ARCHITECTURE NOTE
Render terminates TLS at its edge and forwards HTTP over its internal network.
This patch pins the public URL scheme to the known canonical API host instead
of broadly trusting arbitrary proxy headers. On other deployments, set
DISPLAY_PUBLIC_HTTPS_HOST to that deployment's public API DNS hostname.
